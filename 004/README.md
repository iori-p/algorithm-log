# 問題: 区間の合計

N個の整数 A_1, A_2, ..., A_N が横一列に並んでいます。

Q個の質問が与えられます。j番目の質問では、2つの整数 L_j, R_j が与えられるので、
「A_{L_j} から A_{R_j} までの合計」を答えてください。

## 制約
- 1 ≤ N ≤ 200000
- 1 ≤ Q ≤ 200000
- 1 ≤ A_i ≤ 1000
- 1 ≤ L_j ≤ R_j ≤ N

## 入力形式
N Q
A_1 A_2 ... A_N
L_1 R_1
L_2 R_2
:
L_Q R_Q

## 出力形式
Q行にわたって、それぞれの質問の答えを出力せよ。

## 入力例1
5 3
1 2 3 4 5
1 3
2 4
1 5

## 出力例1
6
9
15
